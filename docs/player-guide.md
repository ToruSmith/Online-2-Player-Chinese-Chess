## 安裝到手機或平板

安裝後會出現在主畫面，打開時沒有網址列；**沒有網路時也能和電腦下棋、解殘局**（線上對戰需要網路）。

| 裝置                 | 做法                                                              |
| -------------------- | ----------------------------------------------------------------- |
| iPhone／iPad         | 用 Safari 打開網址 → 點「分享」→「加入主畫面」                    |
| Android              | 用 Chrome 打開網址 → 右上角選單 →「安裝應用程式」或「加到主畫面」 |
| 電腦（Chrome、Edge） | 網址列右側的「安裝」圖示                                          |

## 遊戲模式

| 模式       | 內容                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------- |
| 線上對戰   | 建立房間，把四位數代碼或連結傳給家人。見[和家人線上下棋](#和家人線上下棋)。                  |
| 和電腦練習 | 小樹苗、小學徒、棋友、高手、棋王五種難度。可以悔棋、看提示。                                 |
| 面對面下棋 | 兩個人共用一台裝置。平板放在中間時，開啟「對坐模式」會把黑方的字轉向對面。                   |
| 殘局挑戰   | 十六道一到三步殺，包含馬後炮、重炮、雙車錯等經典殺法。答錯會退回，讓你再想一次。             |
| 學下棋     | 十二堂互動課程：七種棋子的走法，以及蹩馬腿、塞象眼、王不見王等規則。第一次下象棋從這裡開始。 |
| 我的棋譜   | 自動保存最近五十盤棋，可以逐步回看、做賽後分析，或複製中文棋譜。                             |

**給家長的建議**：孩子第一次玩，可以先走一遍「學下棋」，再和電腦的「小樹苗」下幾盤；
和孩子對戰時，用「讓子」讓孩子一開始就有機會贏。

## 和家人線上下棋

1. 點「線上對戰」→ 建立房間，輸入名字（最多 12 個字）。
2. 選擇設定：
   - **棋鐘**：不限時、每方 5 分鐘（每步加 3 秒）、10 分鐘（每步加 5 秒）或 20 分鐘（每步加 10 秒）。
   - **執紅或執黑**，或隨機。紅方先走。
   - **讓子**：開房的人可以讓一馬、一炮、一車、雙馬或車馬。
   - **提示**：可以關掉，讓雙方都不能看提示。
3. 把畫面上的**四位數代碼**或連結傳給家人，對方輸入代碼（或點連結）就會入座。

對局中：

- **悔棋要對方同意**：送出悔棋後，由對方決定答不答應。提和、再來一局也一樣要對方同意。
- **只有預設訊息**：可以傳「好棋！」「加油！」「讓我想想」「哇！」「再來一局」「抱一個」，沒有打字聊天。
- **斷線不會輸**：手機休眠或網路中斷時，座位會保留，**棋鐘也會暫停**。回到同一個連結就能接著下。
- **觀戰**：兩個座位都坐滿後，其他人打開連結會變成觀戰（最多八人）。
- 結束時會蓋一枚朱印。下完的對局會存在「我的棋譜」。

## 規則重點

走法與一般中國象棋相同（「學下棋」有完整說明）。以下幾點容易和其他軟體不同：

- **困斃判負**：輪到自己卻沒有任何棋可以走，就算沒有被將軍也算輸。
- **長將判負**：同一個局面出現三次時，如果只有一方每一步都在將軍，那一方輸。
- **長捉判負**：同一個局面出現三次時，如果只有一方每一步都在將軍或捉子（而且至少捉了一次），那一方輸。
  「捉子」是指車、馬、炮新攻擊到對方吃了也不會被吃回的棋子；將帥與兵卒不算被捉。
- **重複局面判和**：其他情況下，同一個局面出現第三次就是和棋。
- **自然限著**：連續 60 回合都沒有吃子，和棋。
- **子力不足**：雙方都只剩將（帥）、士、象時，和棋。

這些是簡化過的判定，沒有處理正式比賽裡「長攔」等更細的規則。

## 操作與外觀

- 點一下棋子選起來，再點目的地就會走過去；可以走的位置會標出來。
- **鍵盤**：方向鍵移動，Enter 選子與落子，Esc 取消。
- **主題**：松林、青花、夜弈三種。
- 音效都是即時合成的，可以在設定裡關掉。

## 常見問題

**打開網址要等很久？**
伺服器一段時間沒人用會休息，第一次打開要等它醒來，大約一分鐘。醒來之後就很快了。

**線上對局突然不見了？**
伺服器更新版本或重新啟動時，**還沒下完**的線上對局會消失（已下完的對局存在你自己的裝置上，不受影響）。
很少發生；遇到時請重新建立房間。

**代碼輸入後說找不到房間？**
房間在兩個人都離開 30 分鐘後會自動關閉。確認代碼沒有打錯，或請對方重新建立房間。

**為什麼看到的還是舊版本？**
遊戲會先用裝置上的快取，讓沒有網路時也能開。新版本會在下一次開啟時生效，把分頁或 App 完全關掉再開一次即可。

**我的棋譜不見了？**
棋譜只存在這台裝置的瀏覽器裡。清除瀏覽資料、使用私密瀏覽，或換一台裝置，都看不到原本的紀錄。

## 你的資料

- **不需要帳號**。遊戲不收集姓名、電子郵件，也沒有廣告或追蹤程式。
- **線上對戰**時，你輸入的名字、棋步與房間設定只存在伺服器的記憶體裡，用來讓雙方同步；
  房間關閉或伺服器重新啟動後就不見了，不會寫進資料庫或檔案。名字不要用真實姓名。
- **棋譜與設定**只存在你的瀏覽器裡，不會上傳。
